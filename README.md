# Sixteen Can Wait

An interactive Twine story by Nigel Schlick (Writing 1, Dr. Brian C. Ernst), adapted from the argumentative essay *Why Social Media Needs to Be Restricted to 16*.

**Play it:** open `index.html` in any browser, or visit the GitHub Pages link for this repo.

## The idea

- **Act 1:** You are 13 and just got your first social media account. The more you scroll, the more of the healthy choices get crossed out (a mechanic inspired by *Depression Quest*). Texting a real friend is the only option that is never crossed out.
- **Act 2:** The twist. You are a U.S. Senator casting the deciding vote on the Sixteen Act. You answer the four strongest objections, weigh the cost of being wrong, and vote.

**Target audience:** lawmakers, who have the power to set and enforce a minimum age of sixteen.

## Files

- `index.html`: the playable story (Harlowe 3 format)
- `src/story.twee`: the story source in Twee 3, Twine's plain-text format

## Editing in Twine

In the Twine app, go to **Library → Import** and choose `index.html`. The story opens with all 24 passages so you can edit it visually.

To rebuild from the source instead, use [Tweego](https://www.motoslave.net/tweego/):

```
tweego -o index.html src/story.twee
```
